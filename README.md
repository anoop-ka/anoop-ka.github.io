# Anoop K A — Personal Portfolio

A responsive, dark-tech personal portfolio for **anoopka.github.io**, built with plain HTML, CSS and JavaScript. No build tools or backend are required.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named exactly `anoopka.github.io`.
2. Upload all files and folders from this project to the repository root (not the ZIP file itself).
3. Commit the files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for the deployment to finish. Your site will be available at `https://anoopka.github.io`.

## Before publishing — personalize these details

- Confirm the experience titles, employers and descriptions are accurate.
- Add employment dates if you want them displayed.
- Replace the LinkedIn link in `index.html` with your actual profile URL.
- Add a professional contact email or contact form if desired.
- Link each project card to its actual GitHub repository when you publish the projects.
- Add a downloadable resume PDF if you want a resume button.

## Files

- `index.html` — all page content and sections
- `styles.css` — responsive layout, colors and visual styling
- `script.js` — mobile navigation and current year
- `assets/profile.jpg` — cropped copy of the profile photo supplied for this site
- `assets/favicon.svg` — browser tab icon

## Local preview

Open `index.html` in a browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
